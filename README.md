# science-labs

과학 실험 데이터 분석 프로그램 모음입니다.

## 실험 목록

| 실험 | 폴더 | 설명 |
|---|---|---|
| 보일의 법칙 | [`boyles-law/`](boyles-law/) | 주사기 + 무선 압력센서로 20 mL → 6 mL까지 1 mL씩 측정한 데이터를 붙여넣어 P–V, PV–V, P–1/V 그래프를 그리고, 참가자 전체 평균과 비교합니다. |

## 보일의 법칙 실험 사용법

1. 측정한 CSV 내용을 복사해 붙여넣거나 **CSV 파일 열기**로 불러옵니다.
   - `부피, 압력` 두 열 또는 압력 값만(20 mL → 6 mL 순서) 있어도 인식합니다.
   - 압력은 atm 기준이며, 머리글에 kPa·hPa·mmHg가 있으면 자동으로 atm으로 환산합니다.
2. **그래프 보기** → 나의 결과(그래프 3종, PV 평균·변동, R²)
3. **모두의 결과 보기** → 지금까지 참가자들의 부피별 평균과 비교
4. 오른쪽 아래 톱니바퀴: 저장된 기록 삭제, 전체 데이터 CSV 복사

> 태블릿 가로 모드 기준으로 디자인되었습니다.

## 데이터 저장 (Google 스프레드시트)

참가자 기록은 Google Apps Script 웹 앱을 통해 스프레드시트의 `runs` 시트에 저장되며, 모든 태블릿이 같은 데이터로 평균을 냅니다.
웹 앱 주소는 `boyles-law/index.html`의 `SHEET_URL` 상수에 있습니다.

- 인터넷이 끊기면 기록을 기기에 임시 저장했다가, 다시 연결되면 자동으로 시트에 전송합니다.
- 화면 왼쪽 아래에 연결 상태와 전송 대기 건수가 표시됩니다.
